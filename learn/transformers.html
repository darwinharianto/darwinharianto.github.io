Why Attention Beat RNNs

1. O(1) Path Length

RNNs must step sequentially through $N$ tokens, causing early information to degrade (vanishing gradient across time). Attention computes direct relationships between any two tokens in a single step.

2. Massive Parallelization

Because tokens do not wait for previous hidden states $h_{t-1}$, the entire sequence is computed simultaneously via matrix multiplications on modern GPU tensor cores.

3. Dynamic Context Routing

Unlike fixed convolutional kernels, attention weights are input-dependent: the network dynamically re-routes focus based on semantic relevance.

Subspace Specialization

Instead of performing a single attention function with $d_{\text{model}}$-dimensional keys, queries and values, linearly projecting the queries, keys, and values $h$ times allows the model to jointly attend to information from different representation subspaces.

• $d_{\text{model}} = 512, h = 8 \text{ heads}$
• $d_k = d_v = d_{\text{model}} / h = 64$
• Total compute remains identical to single-head attention!

Vision Transformers (ViT)

ViT discards convolutions entirely by cutting an image into non-overlapping patches (e.g., 16×16 pixels), flattening them, and projecting them linearly into standard 1D token embeddings.

• Image Resolution: 224 × 224
• Patch Size: 16 × 16 → 196 Patches
• Patch Tokens + [CLS] Token + 1D Positional Embeddings
• Fed through standard Transformer Encoder blocks

Unlike CNNs with fixed local inductive biases, ViTs learn both fine textures and global scene topology from scratch, scaling effectively with massive dataset sizes.
