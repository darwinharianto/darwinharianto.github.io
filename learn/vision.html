Spatial Inductive Bias

Standard Dense/MLP layers treat every pixel independently, discarding spatial locality and exploding parameter counts (1024×1024×3 image = 3M inputs per neuron).

1. Translation Equivariance

Shifting an object in the input shifts the activation in the feature map by the exact same amount: f(g(x)) = g(f(x)).

2. Weight Sharing

A 3×3 kernel uses only 9 trainable parameters regardless of image resolution, drastically curbing overfitting.

Architectural Advantages

1. Two 3×3 vs One 5×5

Two stacked 3×3 convolutions have the exact same 5×5 receptive field as a 5×5 kernel, but use only 18 weights instead of 25 (28% fewer parameters) and insert an extra ReLU non-linearity.

2. Dilated (Atrous) Convolutions

Setting dilation $r > 1$ skips adjacent pixels, multiplying the receptive field without adding a single extra parameter or losing spatial resolution to pooling.

Darwin's Production Deployment Pipeline

  • 01. PyTorch Model Freeze: Strip training operators (Dropout, gradient hooks), fold BatchNorm weights directly into preceding Conv layers.
  • 02. ONNX Graph Export & Optimization: Validate dynamic axis dimensions, run ONNX Simplifier to eliminate redundant reshape operations.
  • 03. Post-Training Quantization (PTQ): Feed representative calibration samples through ONNX Runtime to determine optimal activation clipping ranges (KL divergence or MinMax).
