02 Mathematical CP-SAT Formulation

Translating topological Flow Free game physics into exact Integer & Boolean Linear Constraints.

1

Directed Flow Conservation (Kirchhoff's Node Law)

For each color $c \in \{1 \dots K\}$ and every directed edge $(u, v)$ between adjacent grid squares, a Boolean decision variable $x_{u,v}^c \in \{0, 1\}$ dictates path flow:

• Terminals: Out-degree = 1 (Source), In-degree = 1 (Sink)
• Transit Cells: ∑ x(u,v) = ∑ x(v,u) ≤ 1
• Walls (-1): x(u,v) = 0, x(v,u) = 0

Ensures exactly one continuous, self-avoiding directed path connects each color terminal pair without dead-ends or isolated cycles.

2

Global Turn Minimization Objective

Human aesthetics and spatial economy prefer direct, unbent lines. To penalize circuitous bends, the model creates turn indicators $t_u^c \in \{0, 1\}$:

• Turn condition: dir_in(u) ⟂ dir_out(u) ⇒ t_u^c = 1
• Objective: Minimize ∑_{u, c} t_u^c
• Full Board Fill: ∑_{u} filled(u) == (N × M - Num_Walls)

Solved simultaneously using Google OR-Tools CP-SAT with SAT presolve, conflict analysis, and parallel branch-and-bound workers.
