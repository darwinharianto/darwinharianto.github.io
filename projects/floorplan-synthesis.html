LoRA + ControlNet Architecture

Standard text prompts fail to enforce exact spatial geometries. By combining two complementary conditioning paths, we achieved sub-pixel wall alignment:

1. LoRA Adapter: W = W₀ + B · A

Low-rank decomposition matrices ($r=16$) fine-tuned on 3,500 architectural CAD plans to teach room styles, textures, and door swings.

2. ControlNet M-LSD Zero-Convs:

Locks structural boundaries by injecting line segment features directly into UNet residual blocks via $1\times1$ zero-convolutions.

02 Topological IoU Room Verification Pipeline

Automated post-generation algorithmic validation ensuring architectural compliance.

Semantic Mask Binarization

Extracts wall contours and partition polygons using adaptive thresholding and morphological closing operators in OpenCV to isolate individual room enclosures.

Polygon IoU Matching

Computes Intersection-over-Union $\text{IoU} = \frac{|P_{\text{gen}} \cap P_{\text{CAD}}|}{|P_{\text{gen}} \cup P_{\text{CAD}}|}$ between generated wall segments and target CAD specifications.

Adjacency Graph Check

Constructs a planar graph of room connections (e.g., verifying that the bathroom is not accessed exclusively through the kitchen) to prevent nonsensical layouts.
