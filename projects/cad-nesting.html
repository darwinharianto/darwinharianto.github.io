Core Geometry: No-Fit Polygon (NFP)

Standard bounding box nesting results in severe sheet waste for L-shaped, bracket, and curved parts.

Minkowski Difference Formula:
$\text{NFP}_{A,B} = A \oplus (-B) = \{ a - b \mid a \in A, b \in B \}$

If part B's reference point is placed on the boundary of $\text{NFP}_{A,B}$, part B touches part A without overlapping!

Google OR-Tools Solver:
• Formulated integer linear constraints on discrete candidate placement positions.
• Penalized bounding height to maximize remaining contiguous scrap for future cuts.

02 End-to-End System Architecture

From CAD DXF vector geometry parsing to optimized CNC fabrication.

Step 1: CAD Ingestion

DXF Polyline Parsing

Parsed raw AutoCAD DXF files using ezdxf, extracting LWPOLYLINE, SPLINE, and ARC entities into closed polygon loops.

Step 2: Geometry Engine

NFP Precomputation

Constructed exact No-Fit Polygons and Inner-Fit Polygons (IFP) for all part pairings across 0°, 90°, 180°, and 270° candidate rotations.

Step 3: Optimization

OR-Tools Constraint Engine

Solved multi-part placement with bottom-left-fill heuristics and constraint satisfaction to minimize sheet length and maximize nesting density.

Step 4: Output GUI

Interactive Visualizer

Delivered an intuitive desktop GUI allowing factory operators to review arrangements, manually nudge parts, and export optimized CNC laser cutting paths.
