Detection Pipeline Architecture

Manual verification of signed applicant documents created large administrative backlogs. We developed an automated layout parsing and Japanese name entity extraction system:

1. Document Layout Decomposition:

Deconstructs asymmetrical property survey PDFs into dual functional domains: parsing non-grid cadastral maps (地番図) on one side and structured tabular metadata on the other using morphological kernel line extraction.

2. Signature Target Box (ROI) Localization:

Identifies table cell geometries and isolates the designated signature block (氏名・自筆署名欄). Applies perspective rectification to correct document scanning skew.

3. Japanese Name OCR & NER Matching:

Runs character recognition coupled with a comprehensive Japanese Surname & Given Name dictionary. Specifically validates person name morphology, rejecting non-person text, empty blocks, and corporate seal imprints.

4. 99% Accuracy & Labor Reduction:

Automates document intake triage at 99% accuracy across thousands of diverse document submissions, reducing human inspection workload by over 90%.
