Single-Image 3D Algorithm

1. Bolt & Torque Mark Mask:

Detects the hexagonal bolt head and performs color-segmented mask extraction for the witness line stripe painted across the nut and flange surface.

2. Monocular 3D Depth Projection:

Back-projects segmented 2D line pixels $(u, v)$ with predicted metric depth $Z$ using the calibrated iPhone intrinsic matrix: $$X = \frac{(u - c_x) Z}{f_x}, \quad Y = \frac{(v - c_y) Z}{f_y}$$

3. 3D Angle Calculation:

Calculates the 3D directional vector of the bolt line $\vec{v}_{\text{bolt}}$ and flange baseline $\vec{v}_{\text{base}}$: $$\theta = \arccos\left(\frac{\vec{v}_{\text{bolt}} \cdot \vec{v}_{\text{base}}}{\|\vec{v}_{\text{bolt}}\| \|\vec{v}_{\text{base}}\|}\right)$$ eliminating optical perspective distortion from non-perpendicular camera angles.

4. CoreML INT8 Quantization:

Compressed the ensemble network by 75% enabling deep multi-stage inference (detection, segmentation, depth) to execute entirely offline on-device without cloud dependence.
